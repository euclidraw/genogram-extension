# alid 가계도 확장

상담 중 내담자에서 부모·형제·배우자·자녀로 확장하는 관계 기반 가계도 확장입니다. 모든 가족 관계는 엔티티 참조로 저장하고 선의 기하는 파생 계산합니다.

## 설치·개발

alid 확장 관리자에서 이 저장소의 `alid.extension.json`을 지정하고 신뢰 승인 후 설치합니다. 배포 번들은 `dist/plugin.js` 한 파일입니다.

```sh
pnpm install
pnpm test
pnpm dev
# 인접 alid 소스와 실제 커널 계약 검증
pnpm test:host
# 다른 위치의 호스트 사용
ALID_PATH=/path/to/alid pnpm test:host
```

## 상담 흐름

1. 도구 선반의 **내담자·인물 추가**로 시작합니다. 첫 인물에는 IP가 지정됩니다. 속성에서 이름·나이·기호·상태를 편집합니다.
2. 인물을 선택하고 **부모 추가**, **손위 형제**, **손아래 동생**, **배우자 추가**, **자녀 추가**, **쌍둥이 추가**를 실행합니다. 단축키는 각각 `M-p`, `M-[`, `M-]`, `M-s`, `M-c`, `M-t`입니다. `M`은 Alt입니다. 부모를 모르면 부모 노드를 미상 기호로 먼저 추가합니다.
3. 재혼 시 배우자를 추가하면 반대편 슬롯과 다른 결합선 높이를 사용합니다. 배우자가 여러 명인 경우 해당 **부부 관계선 하나를 선택**해 자녀를 추가합니다.
4. 기존 두 인물을 선택해 부부·부모→자녀·쌍둥이·정서 관계를 연결합니다. 부모→자녀와 방향성 관계는 **선택 순서가 방향**입니다. 쌍둥이는 같은 부모에 먼저 연결되어 있어야 합니다.
5. 인물 여러 명을 선택해 **동거 가구로 묶기**(`C-c g`)를 실행합니다. 가구 테두리와 인물을 함께 선택해 편입·제외합니다. 부부선·가구 경계를 선택해 이동하면 구성원도 함께 움직입니다.
6. 선을 선택하면 유형 변경 컨트롤과 다이아몬드 핸들이 표시됩니다. 드래그는 임시 미리보기이며 놓을 때 확정합니다. Escape·캡처 상실은 취소합니다.
7. **가족 정돈**은 선택된 인물 또는 전체 가족을 세대와 형제 순서에 맞춰 정돈합니다. 자동 실행하지 않습니다.
8. 확장 설정 위치의 **이름 표시 방식 전환**, **연도 마스킹**, **정서선·가구·메모 표시 전환**은 정본을 바꾸지 않고 화면과 SVG 출력에 적용됩니다. 표시 옵션은 워크스페이스 설정으로 저장되어 재시작·재활성화 후에도 유지됩니다.

핵가족·3세대·한부모·재혼 템플릿은 속성 패널에서 삽입할 수 있습니다. 템플릿과 가족 확장은 각각 하나의 정본 배치 및 Undo 그룹으로 적용됩니다.

## 검증 범위

자동 테스트는 참조 스키마, 순수 파생, SVG 텍스트 이스케이프, 가족 생성, 순환 거부, 관계 반전, 동거 가구, 출력 렌즈, 선 선택, 번들 해시와 개발 서버를 검증합니다. 호스트 검증은 실제 alid CanvasWorld에 다섯 어스펙트를 등록하고 템플릿 파생·읽기 순수성·부모 삭제 폴백을 확인합니다.

인물을 선택해 Enter를 누르거나 이름·나이·연도·메모를 더블클릭하면 직접 편집합니다. Tab/Shift+Tab으로 필드를 옮기고 Enter/Escape로 닫습니다. 인물 추가 직후에는 이름 편집을 시작합니다. 한국어 조합 중에는 종료 키를 무시하고 원격 변경은 조합 확정 시 병합합니다.

인물 위쪽의 ↔ 핸들로 이동하면 다른 가족 구성원의 세대(240)·형제 간격(110)에 화면 8px 이내로 접근할 때 맞춰집니다. 기본 몸체 드래그는 호스트의 선택·스냅 동작을 따릅니다. 핸들 드래그의 Escape·포인터 캡처 상실은 정본 쓰기 없이 취소됩니다.

확장 0.1.1은 alid 커널 0.1.1 이상(0.1.x)과 새 공개 서비스 `extensions.preferences`가 필요합니다. 호스트 변경 설명은 alid 저장소 `docs/extension-preferences.md`에 있습니다. 이전 호스트에는 이 변경을 먼저 반영해야 합니다.

호스트 통합 검사는 실제 Rust Undo/Redo, JSONL 읽기 순수성, DOM 없는 SceneVectorCompiler 출력 및 임시 드래그 기하 배제, 외부 패키지 로더와 설정 재로드를 검증합니다. OS 한국어 입력기·분할 뷰 수동 검증과 1,000개 엔티티 120fps·0-GC 실측은 자동 테스트 통과와 구분합니다. SVG 기호는 기관별 표기 차이에 맞춰 검토해야 합니다.

## 선택 메뉴

도구 선반에는 인물 추가 아이콘 하나를 둡니다. 인물 두 명 선택 시 부부·부모자녀·정서 관계 연결과 동거 가구 묶기 아이콘만 나타나며, 가구 묶기는 세 명 이상에서도 사용할 수 있습니다. 버튼 이름은 툴팁과 접근성 라벨로 제공됩니다. 관계선 유형·세부 설정·가족 확장·템플릿은 속성 패널에서 변경하고 모든 명령은 팔레트에서도 실행할 수 있습니다. 선택한 인물 주변에는 부모·배우자·자녀 추가 핸들과 이동 핸들만 표시합니다.

### 임상 상태 표기

사용자가 제공한 임상 상태 범례를 따릅니다. 오른쪽 반쪽 음영은 신체 질환, 아래쪽 음영은 약물·알코올 남용, 아래쪽 사선과 가로 경계는 남용 의심을 나타냅니다. 왼쪽 아래 음영과 가로선은 남용 회복, 세로선은 신체·심리 질환 호전을 나타냅니다. 회복과 질환이 함께 있는 상태 및 심각한 정신·신체 문제와 물질 사용의 공존도 별도로 선택할 수 있습니다. 기존 ‘정신 건강’ 값은 기존 왼쪽 음영을 유지합니다.

흡연, 비만, 언어 문제 표시는 임상 상태와 독립적으로 선택할 수 있습니다. 각각 오른쪽 위 점, 안쪽 원, 아래쪽 사선으로 나타냅니다.

기존에 저장된 ‘회복 중’은 회복 대상이 기록되지 않아 **R**로 표시합니다. 이 표시는 기존 기록의 유형 미지정을 나타내는 자체 표기이며, 구분이 확인되면 ‘물질 사용 회복 중’ 또는 ‘신체·정신 질환 관해’를 선택하세요. 기호는 진단을 확정하지 않으며 문서의 맥락과 함께 해석해야 합니다.

### 관계선 표기

새 정서 관계선은 붉은색 직선으로 생성되며, 속성에서 색을 변경할 수 있습니다. 선을 선택하고 곡률 조절 핸들을 드래그하면 필요한 만큼 휘게 할 수 있습니다. 같은 인물 사이에 관계선이 여러 개 있으면 처음에는 겹칠 수 있습니다.

[Genogram 편집기](https://genogram.kr/editor)의 공개 관계선 구성을 참고해 친밀은 두 줄, 융합은 세 줄, 적대는 지그재그로 표시합니다. 친밀·적대와 융합·적대는 평행선과 지그재그를 함께 사용합니다. 관계 집중은 열린 화살표, 돌봄은 이중 열린 화살표, 신체적 학대는 채운 화살표, 정서적 학대는 빈 화살표, 성적 학대는 두 줄·지그재그와 채운 화살표를 사용합니다. 방향을 가진 관계는 시작 인물에서 대상 인물로 향합니다.

별거·이혼은 결합선에 각각 한 개·두 개의 사선을 표시하고, 재결합에는 원을 더합니다. 위탁 자녀선은 파선, 입양 자녀선은 실선과 파선을 함께 표시합니다. 대리 출생에는 선 옆에 ‘대리’라고 명시합니다. 약혼·비공식 관계는 결합선의 점선 간격으로 구분하며, 이 부분은 해당 편집기의 표기를 확인한 결과가 아닌 이 확장의 구분 방식입니다.

## 관계선 선택과 조절

확장 0.1.2부터 정서·부부·부모자녀 관계의 호버·선택 윤곽은 실제 선과 기호 경로를 따릅니다. 점선과 라벨 사이의 공백도 보존합니다. 부부선 높이는 상태 기호를 피한 가로 구간에서, 부모자녀 분기 높이는 공유 형제 바에서 조절합니다. 형제 분기는 함께 미리 보고 한 번에 확정합니다. 정서 관계의 다이아몬드 핸들은 선에 수직인 방향으로 드래그해 곡률을 바꿉니다. 조절 결과는 놓을 때만 저장하고 Escape·캡처 상실은 취소합니다.
