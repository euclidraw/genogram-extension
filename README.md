# alid 가계도 확장

상담 중 내담자에서 부모·형제·배우자·자녀로 확장하는 관계 기반 가계도 확장입니다. 모든 가족 관계는 엔티티 참조로 저장하고 선의 기하는 파생 계산합니다.

## 설치·개발

alid 확장 관리자에서 이 저장소의 `alid.extension.json`을 지정하고 신뢰 승인 후 설치합니다. 배포 번들은 `dist/plugin.js` 한 파일입니다.

```sh
pnpm install
pnpm test
pnpm dev
# 인접 alid 소스와 실제 커널 계약 검증
pnpm test:host
# 다른 위치의 호스트 사용
ALID_PATH=/path/to/alid pnpm test:host
```

## 상담 흐름

1. 도구 선반의 **내담자·인물 추가**로 시작합니다. 첫 인물에는 IP가 지정됩니다. 속성에서 이름·나이·기호·상태를 편집합니다.
2. 인물을 선택하고 **부모 추가**, **손위 형제**, **손아래 동생**, **배우자 추가**, **자녀 추가**, **쌍둥이 추가**를 실행합니다. 단축키는 각각 `M-p`, `M-[`, `M-]`, `M-s`, `M-c`, `M-t`입니다. `M`은 Alt입니다. 부모를 모르면 부모 노드를 미상 기호로 먼저 추가합니다.
3. 재혼 시 배우자를 추가하면 반대편 슬롯과 다른 결합선 높이를 사용합니다. 배우자가 여러 명인 경우 해당 **부부 관계선 하나를 선택**해 자녀를 추가합니다.
4. 기존 두 인물을 선택해 부부·부모→자녀·쌍둥이·정서 관계를 연결합니다. 부모→자녀와 방향성 관계는 **선택 순서가 방향**입니다. 쌍둥이는 같은 부모에 먼저 연결되어 있어야 합니다.
5. 인물 여러 명을 선택해 **동거 가구로 묶기**(`C-c g`)를 실행합니다. 가구 테두리와 인물을 함께 선택해 편입·제외합니다. 부부선·가구 경계를 선택해 이동하면 구성원도 함께 움직입니다.
6. 선을 선택하면 유형 변경 컨트롤과 다이아몬드 핸들이 표시됩니다. 드래그는 임시 미리보기이며 놓을 때 확정합니다. Escape·캡처 상실은 취소합니다.
7. **가족 정돈**은 선택된 인물 또는 전체 가족을 세대와 형제 순서에 맞춰 정돈합니다. 자동 실행하지 않습니다.
8. 확장 설정 위치의 **이름 표시 방식 전환**, **연도 마스킹**, **정서선·가구·메모 표시 전환**은 정본을 바꾸지 않고 화면과 SVG 출력에 적용됩니다. 현재 표시 옵션은 세션 동안 유지합니다.

핵가족·3세대·한부모·재혼 템플릿을 도구 선반에서 삽입할 수 있습니다. 템플릿과 가족 확장은 각각 하나의 정본 배치 및 Undo 그룹으로 적용됩니다.

## 검증 범위

자동 테스트는 참조 스키마, 순수 파생, SVG 텍스트 이스케이프, 가족 생성, 순환 거부, 관계 반전, 동거 가구, 출력 렌즈, 선 선택, 번들 해시와 개발 서버를 검증합니다. 호스트 검증은 실제 alid CanvasWorld에 다섯 어스펙트를 등록하고 템플릿 파생·읽기 순수성·부모 삭제 폴백을 확인합니다.

실제 브라우저 한국어 IME, Rust Undo/Redo, 포인터 기즈모 및 분할 뷰 수동 검증, 전체 씬 SVG 출판 비교와 1,000개 엔티티 성능 계측은 별도로 필요합니다. 가족 전용 이동 레일 스냅과 직접 인라인 편집기는 아직 제공하지 않으며 호스트의 기본 스냅과 속성 편집기를 사용합니다. SVG 기호는 기관별 표기 차이에 맞춰 검토해야 합니다.
